# DEKABYTE MVP — Georgian Technology Studio

ეს არის **DEKABYTE**-ის ოფიციალური, გაყიდვებზე ორიენტირებული და სრულად ადაპტირებული MVP ვებსაიტი, შექმნილი React, TypeScript და Tailwind CSS ტექნოლოგიური სტეკით. ვებსაიტი სრულად ლოკალიზებულია ქართულ ენაზე და ოპტიმიზებულია საძიებო სისტემებისთვის (SEO).

---

## 🛠️ პროექტის გაშვება და დეველოპმენტი

პროექტი არის პორტატული და დამოუკიდებელი. მისი გაშვება შესაძლებელია ნებისმიერ ლოკალურ გარემოში სტანდარტული npm ბრძანებებით.

### 1. დამოკიდებულებების ინსტალაცია
```bash
npm install
```

### 2. ლოკალური სერვერის გაშვება (დეველოპმენტი)
```bash
npm run dev
```
საიტი გაიშვება მისამართზე: `http://localhost:3000`

### 3. საწარმოო ვერსიის აწყობა (Build)
```bash
npm run build
```
აწყობილი ფაილები განთავსდება `dist/` საქაღალდეში.

## 🚀 Vercel-ზე დეპლოი (Deployment)

პროექტი სრულად თავსებადია Vercel-ის პლატფორმასთან. ვინაიდან გამოიყენება კლიენტ-სერვერული როუტინგი (React Router), გვერდის რეფრეშისას 404 შეცდომის თავიდან ასაცილებლად შექმნილია `/vercel.json` ფაილი შესაბამისი გადამისამართებებით:

### დეპლოის ნაბიჯები:
1. დააკავშირეთ თქვენი GitHub რეპოზიტორი Vercel-თან.
2. აირჩიეთ **Vite** კონფიგურაცია.
3. ბრძანებები დაყენდება ავტომატურად (`npm run build`).
4. დააჭირეთ **Deploy**-ს.

## 📂 პროექტის სტრუქტურა და მონაცემთა მოდიფიკაცია

საიტის სრული კონტენტი, კონტაქტები და პროექტები გამოყოფილია კომპონენტებისგან და ინახება მარტივად წასაკითხ ფაილებში.

### 1. საკონტაქტო და ბრენდის ინფორმაციის შეცვლა
გახსენით `/src/data/site.ts` და შეცვალეთ შემდეგი ველები:
* `email`: კომპანიის ელფოსტა
* `phone`: ტელეფონის ნომერი ბმულებისთვის
* `phoneFormatted`: ტელეფონი ვიზუალური წარდგენისთვის
* `whatsappUrl`: WhatsApp ჩატის ლინკი
* `messengerUrl`: Facebook Messenger ჩატის ლინკი
* `facebookUrl`: ფეისბუქ გვერდის ლინკი
* `linkedinUrl`: კომპანიის LinkedIn პროფილი
* `githubUrl`: GitHub გვერდი

### 2. პორტფოლიოს პროექტების დამატება / რედაქტირება
გახსენით `/src/data/projects.ts` და დაამატეთ ან შეცვალეთ პროექტების მასივი:
* `slug`: უნიკალური იდენტიფიკატორი ბრაუზერის მისამართისთვის (`/work/:slug`)
* `title`: პროექტის სახელი
* `category`: კატეგორია / პროდუქტის ტიპი
* `shortDescription`: მოკლე აღწერა ბარათებისთვის
* `description`: დეტალური აღწერა ქეისისთვის
* `objective`: პროექტის მიზანი
* `whatWasCreated`: შექმნილი მოდულების სია (მასივი)
* `features`: ფუნქციონალის სია (მასივი)
* `technologies`: ტექნოლოგიური ტეგები (მასივი)
* `design`: დიზაინის პარამეტრები (თემა, ფერები, mockup ტიპი)

### 3. მომსახურებების რედაქტირება
მომსახურებების ბარათების რედაქტირება შესაძლებელია `/src/data/services.ts` ფაილში.

### 4. ხშირად დასმული კითხვების (FAQ) რედაქტირება
FAQ სექციის კითხვა-პასუხები მოცემულია `/src/data/faq.ts` ფაილში.

## 🎨 ვიზუალური აქტივების შეცვლა (Assets)

* **Favicon-ის შეცვლა**: ფავიკონის სახით ამჟამად გამოიყენება SVG ემოჯი `/index.html`-ში. მისი ჩანაცვლება შეგიძლიათ ჩვეულებრივი ფაილით `<link rel="icon" href="/favicon.ico">` ხაზის დამატებით.
* **Open Graph (გაზიარების სურათი)**: შეცვალეთ სურათი `/public/assets/og-image.jpg` მისამართზე.
* **პროექტების სურათები**: პროექტების ვიზუალები აგებულია სუფთა, ინტერაქტიული HTML/CSS Mockup-ებით, რაც გამორიცხავს გატეხილი სურათების არსებობას. თუ მომავალში რეალური სურათების ჩანაცვლება დაგჭირდებათ, შეგიძლიათ დაამატოთ `image` ველი პროექტის მონაცემებში და ასახოთ `<img>` ტეგი შესაბამის კომპონენტში.
